# DotNet Login Example 🔑
โปรเจกต์ตัวอย่างการสร้างระบบ Login เบื้องต้นด้วย ASP.NET Core MVC

### เทคโนโลยีที่ใช้
- C# .NET
- ASP.NET Core MVC
- Razor Pages (HTML/CSS)

### วิธีการใช้งาน
1. ตรวจสอบโค้ดการจัดการข้อมูลที่ `Models/LoginViewModel.cs`
2. ดูการแสดงผลหน้าจอที่ `Views/Account/Login.cshtml`
